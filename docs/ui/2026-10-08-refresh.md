# BJYO 界面改造

本次保留 Spring Boot、Thymeleaf、Shiro、Bootstrap 3 和已有管理插件，统一登录、注册、导航、工作台、查询条件、表格、表单与弹窗的视觉风格。

## GitHub 参考

- [Tabler](https://github.com/tabler/tabler)：参考清晰的内容布局、轻量卡片、留白和控件层次。
- [Vben Admin](https://github.com/vbenjs/vue-vben-admin)：参考导航、页签与工作空间的组织方式。
- [RuoYi-Vue-Plus](https://github.com/dromara/RuoYi-Vue-Plus)：参考 Java 管理后台的功能组织。

以上项目仅用于设计参考。本次 CSS 和模板调整为本项目编写，没有引入它们的源码或运行依赖。

## 实现

- `bjyo-theme.css` 提供统一颜色、圆角、文字与焦点样式。
- `bjyo-auth.css`、`bjyo-shell.css`、`bjyo-workbench.css`、`bjyo-pages.css` 分别管理认证、导航、工作台和管理页面。
- 工作台入口使用与目标页面一致的 Shiro 权限，支持受限账号和无权限时的空状态。
- 在后台 iframe 内通过已有 `createMenuItem` 打开页签；独立访问工作台时使用普通链接。保留 Ctrl、Command、Shift 等浏览器操作。
- 登录表单增加可关联标签与自动填充提示，移除页面上预填的默认账号密码，保持现有字段名、验证码开关和提交接口。
- 样式资源的版本参数更新为 `20261008`，避免复用旧样式缓存。
